キー・コントローラー・タッチで、セツナを動かし、攻撃のコンボや必殺・月華鎖葬が使えます。場にはレプリカの街が広がっています。T キー（コントローラーは View／Create、タッチは「相手」）で、相手を木人 → ドラゴン（蒼鱗の竜） → ゴーレム軍団の順に切り替えられます。ドラゴンまたはゴーレム軍団にすると、互いのHPバーが出て戦闘できます。HPの表示はセツナが 1,000、竜が 400,000。ゴーレム軍団は、左右にアイスゴーレム（表示HP 25,000）が2体、真ん中に1.5倍の大きさのフレアゴーレム（表示HP 150,000）が1体です。アイスゴーレムは木人と同じく打ち上げられ、氷の弾を3つ扇形に撃ってきます。フレアゴーレムはドラゴンと同じく重い相手で、必殺「残像分身・紅蓮三角陣」を使います。一体を倒すと「（名前） 撃破！」、全員を倒すと「ゴーレム軍団 制圧」が出ます。竜を倒すと「撃破！」です。

セツナのライフは3です。操作中のセツナまたはトワは、被弾すると「やられ」モーション（頭と胸がのけぞり、膝が沈んで踏ん張って構え直す、約0.55秒）が出ます。力尽きると「力尽きる」モーション（のけぞり、よろめき、膝から崩れ、前のめりに倒れ伏す）のあと、「戦闘不能…　残りライフ N」と出て、「起き上がり」モーション（腕で上体を起こし、立膝から立ち上がる、約1.8秒）とともに「再起！」します（再起のあと約2.5秒は無敵）。復活は2回までで、3回倒れると「力尽きた…」のあと GAME OVER になります。ドラゴンを倒すか、ゴーレム軍団を全滅させると、奥義や隠し評価の祝福が終わったあと「MISSION COMPLETE」と RESULT（ランク評価）が出ます。全滅したゴーレム軍団が、その場ですぐ再配置されることはありません。

V キー（コントローラーは RS押し込み／R3、タッチは「交代」）で、操作キャラをセツナとトワで交代できます。トワの必殺は天輪十閃で、踏み込んでから高速の回転斬りを重ね、締めの一閃で終わります。B キー（コントローラーは十字←、タッチは「仲間」）で、操作していない方のキャラを仲間として呼び出せます。仲間はAIで自動戦闘し、連続攻撃や迅雷、必殺（トワは天輪十閃、セツナは月華鎖葬の簡略版）で戦います。仲間がいるときに交代すると、交代したもう一人がそのまま仲間になります。もう一度同じ操作をすると、仲間は戻ります。

ヒットをつなぐほど ULTIMATE ゲージがたまり、99HIT でたまりきります（ヒットが2秒半ほど途切れるとヒット数は0に戻ります。奥義のあいだは約9秒）。つないだヒット数に応じて、いまのコンボのランクが表示されます。段階は D（1HIT）凡、C（20）良、B（50）優、A（100）華、S（200）雅、SS（350）絢爛、SSS（500）天衣無縫です。ヒットが途切れても、その戦いでの最高ランクは残ります。また、50HITごとに与ダメージが 1.16 倍ずつ上がります。たまった状態で必殺技を出し、その最中にもう一度必殺の操作をすると奥義になります。セツナは奥義・太陽風が発動し、続いてクレムゾンフレアでレプリカの街が粉々に弾けます。トワは天輪十閃の回転斬りのあいだに奥義・ライトニングプラズマが発動し、続いてライトニングボルトで、中央と場に散開した電流の柱を打ちおろして街を破壊します。奥義の途中は相手のHPが1までしか減らず、止めの一撃（表示 5,000 にヒット補正を掛けたダメージ）で決着します。これで倒したときだけ ULTIMATE BREAK が出ます。倒せないと「耐えた…！」です。ゲージは奥義のあと0からため直しです。街は奥義のあと約2.5秒で元に戻ります。

RESULT のランクは、その戦いでの最高コンボ評価です。クリア時は「RESULT ── 総合評価」で、クリアタイムと残りライフ、最大コンボ、撃破数、ULTIMATE BREAK の回数が付きます。力尽きたときは「GAME OVER」と「あなたの最高評価」で、最大コンボ、撃破数、ULTIMATE BREAK の回数が付きます。SSS（500HIT以上）のまま奥義の止めで相手を倒すと、隠し最高評価 X「神域到達」になります。祝福の文言は「SSSの極致で奥義を決めし者だけが至る、幻の評価。」「──おめでとう。その剣は、神域に届いた。」で、総合評価も X になります。画面は約2.5秒後から、Enter、コントローラーの A（PS5は ×）、またはタップで閉じられます（攻撃・必殺・迅雷・ジャンプでも可）。クリア後は「次のミッション開始！」、失敗後は「再挑戦！」で、同じ相手でもう一度始まります。

ドラゴン戦では、竜のHPが約3%減るごとにダークスピリットが召還されます（最大16体）。スピリットは竜のまわりを回り、セツナへ光弾を放ちます。奥義や街の崩壊が起きると、スピリットも消えます。空はふだんは宇宙で、ヒットやコンボ、必殺のあいだはデータレインの流れる電脳の空に、奥義のあいだはネオンが反転する空に変わります。

C キー（コントローラーは十字→、タッチは「共闘」）でクラウドを呼び出して共闘できます。クラウドはセツナのそばについて歩き、敵が近くにいると「コンパスチェイン」で鎖を振るい、叩きつけます。叩きつけのとき、取りこんだ弾を「弾幕返し」として敵へ跳ね返すことがあります。もう一度同じ操作をすると、クラウドは戻ります。

G キー（コントローラーは十字↑、タッチは「時止め」）で、クラウドの特殊必殺・静止世界〈クロノ・コンパス〉が使えます。セピアの静止空間が広がり、敵と弾の動きが8秒止まります。味方は動けるままです。クラウドが場にいなければ、呼び出してから発動します。

ゴーレム軍団では、ターゲットを切り替えられます。キーボードは X で次、Z で前。コントローラーは RT（PS5は R2）で次、LT（L2）で前。タッチは「標的」。闇のスピリットは対象外です。HPバーは、いま狙っている一体の名前と残量を表示します。

BGM と効果音つきです。BGM は M キー、効果音は N キー、または左上の ♪ と SE でON/OFFできます。

キーボード：移動は WASD または矢印キー。走るは Shift を押しながら移動。攻撃（連打でコンボ）は J またはクリック。迅雷ダッシュ（7m）は K、必殺・月華鎖葬は L（どちらも攻撃でキャンセル）。99HIT以上なら、必殺技中にもう一度 L で奥義。ジャンプは Space、手を振るは E、背伸びは Q。カメラはマウスのドラッグ、ホイールでズーム。位置リセットは R。相手の切り替え（木人 → ドラゴン → ゴーレム軍団）は T。ターゲット切り替え（次／前）は X／Z。クラウド特殊必殺・静止世界は G。共闘（クラウドを呼び出す／戻す）は C。操作キャラ交代（セツナ ⇄ トワ）は V。仲間（もう一人を呼び出す／戻す）は B。BGM は M、効果音は N。操作説明の ON/OFF は H、または左上の ？。RESULT のあとは Enter（攻撃・必殺・迅雷・ジャンプでも可）。

攻撃連打：切り抜け×2 → 打ち上げ → 空中切り抜け×2 → 墜天。

コントローラー（Xbox）：移動は左スティック、走るは L3（左スティック押し込み）。攻撃は X、迅雷ダッシュは A、必殺は B（奥義も必殺技中に B）、ジャンプは Y。クラウド特殊必殺・静止世界は十字↑。位置リセットは Menu。相手の切り替えは View、ターゲット切り替えは RT（次）／LT（前）、共闘は十字→、仲間は十字←、操作キャラ交代は RS押し込み、操作説明は十字↓。カメラは右スティック、LB・RB でズーム。PS5 は □ / × / ○ / △、L3、L1・R1、R3、OPTIONS、Create、R2（次）／L2（前）に対応します。背伸びはキーボードの Q か、タッチの「背伸び」です。RESULT のあとは A（PS5は ×）。

タッチ：画面左側をなぞって移動（スティックを大きく倒すと走る）。攻撃は「斬」、迅雷ダッシュは「迅雷」、必殺は「必殺」（奥義も必殺技中に「必殺」）、ジャンプは「跳」、手を振るは「手を振る」、背伸びは「背伸び」、位置リセットは「リセット」、相手の切り替えは「相手」、ターゲット切り替えは「標的」、クラウド特殊必殺・静止世界は「時止め」、共闘は「共闘」、操作キャラ交代は「交代」、仲間は「仲間」。画面右側をドラッグ、2本指でズーム。RESULT のあとはタップ。
