キー・コントローラー・タッチで、セツナを動かし、攻撃のコンボや必殺・月華鎖葬が使えます。場にはレプリカの街が広がっています。T キー（コントローラーは View／Create、タッチは「相手」）で、相手を木人 → ドラゴン（蒼鱗の竜） → ゴーレム軍団の順に切り替えられます。ドラゴンまたはゴーレム軍団にすると、互いのHPバーが出て戦闘できます。HPの表示はセツナが 1,000、竜が 400,000。ゴーレム軍団は、左右にアイスゴーレム（表示HP 25,000）が2体、真ん中に1.5倍の大きさのフレアゴーレム（表示HP 150,000）が1体です。アイスゴーレムは木人と同じく打ち上げられ、氷の弾を3つ扇形に撃ってきます。フレアゴーレムはドラゴンと同じく重い相手で、必殺「残像分身・紅蓮三角陣」を使います。一体を倒すと「（名前） 撃破！」、全員を倒すと「ゴーレム軍団 制圧」が出ます。竜を倒すと「撃破！」です。

ドラゴン戦では、戦闘開始20秒後から45秒ごとに重力反転（15秒間、18m上の天井へ落ち、こちらの攻撃は届かない）が起き、体力が50%以下になると狂暴化・アナザーディメンジョン（討伐まで永続。街が消えて30mのキューブに閉じ込められる）になります。

セツナのライフは3です。操作中のセツナまたはトワは、被弾すると「やられ」モーション（頭と胸がのけぞり、膝が沈んで踏ん張って構え直す、約0.55秒）が出ます。力尽きると「力尽きる」モーション（のけぞり、よろめき、膝から崩れ、前のめりに倒れ伏す）のあと、「戦闘不能…　残りライフ N」と出て、「起き上がり」モーション（腕で上体を起こし、立膝から立ち上がる、約1.8秒）とともに「再起！」します（再起のあと約2.5秒は無敵）。復活は2回までで、3回倒れると「力尽きた…」のあと GAME OVER になります。ドラゴンを倒すか、ゴーレム軍団を全滅させると、奥義や隠し評価の祝福が終わったあと「MISSION COMPLETE」と RESULT（ランク評価）が出ます。全滅したゴーレム軍団が、その場ですぐ再配置されることはありません。

V キー（コントローラーは RS押し込み／R3、タッチは「交代」）で、操作キャラをセツナ → トワ → チョコ → ハーバー → テトラの順に交代できます。トワの必殺は天輪十閃で、踏み込んでから高速の回転斬りを重ね、締めの一閃で終わります。チョコまたはハーバーに交代すると、直前に操作していたキャラが仲間として残ります。B キー（コントローラーは十字←、タッチは「仲間」）で、操作していない方のキャラを仲間として呼び出せます。仲間はAIで自動戦闘し、連続攻撃や迅雷、必殺（トワは天輪十閃、セツナは月華鎖葬の簡略版）で戦います。仲間がいるときに交代すると、交代したもう一人がそのまま仲間になります。もう一度同じ操作をすると、仲間は戻ります。

チョコは虚空演算機の演算ファイターです。見た目の大きさは小さく調整されています。移動操作はできず、ホバーチェアで最も近い敵から約8mを保って自動で旋回し、攻撃や弾を自動回避します。戦いは画面下の「虚空演算機」で行います。標的を「分析」（3秒）して記号や数値の要素を抽出し、最大16個まで預けます。式は要素1〜3個で、×と÷を先に計算します。√・±反転・|x|・交換は直前の要素にかかる関数です。結果は式のいちばん左のライフ値（チョコ／HEAT／敵）に入り、ライフ値がなければ新しい数値になります。敵の「ライフ値(1/15)」は敵のHPと直結していますが、通常は最大100に制限して見え、変えた差分だけがHPに反映されます。オーバードライブ中は制限がなく、本来の値（例：フレアゴーレム 150,000 → 10,000）が見えます。チョコのライフと HEAT値は常に使えます。交換はオーバードライブ中だけ、チョコのライフがマイナスのときに使えます。言葉（炎・氷・三角形・残像・プロジェクタイル）が絡む演算は掛け算だけが有効で、効果がない組み合わせは不発（黒煙）です。炎×氷は、炎側と全アイスゴーレムのライフを相殺して対消滅します。E（演算機の「ドロー」）で、言葉か −9〜9 の数字をランダムに2枚入手できます（8秒ごと）。ドローの要素は1回きりで、実行した式に使うと消えます（不発なら残ります。分析で得た要素は使いません）。使える演算子は演算のたびにランダムで絞られ、増やす手段（＋・×・|x|）と減らす手段（−・÷・√）は必ず1つずつ以上含まれます。チョコに切り替えた直後（約3.2秒の起動）と、演算後のクールダウン中は「NEXT OPERATORS」で次に使える演算子が抽選されます。チョコは常に標的とエネルギーラインでつながり、2秒に1HITが入ります。通常、ダメージや回復のやりとりは最大9,999、チョコの最大ライフは1,000です。やりとりした数値（最大9,999）の1/300がHIT数に加算されます。99HITで必殺ボタン（L／コントローラーの B）を押すとオーバードライブ（30秒）になり、敵ライフ値100の上限と9,999の制限が外れ、交換が使えます。ソニックウェイブが出た場合は、その演出のあとで終了します。終わるとチョコのライフ上限は1,000に戻ります。オーバードライブ中に敵へ1,000万を超えるダメージを与えると奥義・ソニックウェイブが発動し、街を粉砕して敵全員に同じダメージを与えます。それで掃討できれば ULTIMATE BREAK となり、総合評価は必ず X になります。チョコのHPが0以下になっても30秒は死なない（存在猶予）ので、そのあいだにライフをプラスに戻せば復帰します。猶予が切れるとライフを1つ失い、まだ残っていれば「再演算 ── 復帰！」します。大きな数値を動かすほど FLOW（回避が強化される）が上がります。演算ごとに3秒〜8秒（やりとりした数値の大きさに比例。絶対値10,000まで）のクールダウンがあり、その間は演算機が消えます。オーバードライブ中はクールダウンはありません。演算するたびに HEAT が溜まり（10＋最大25。扱った数値が大きいほど多い。毎秒1.5ずつ冷える）、100で OVERHEAT となり15秒行動不能になります（演算機が消え、回避も鈍ります）。明けると HEAT は40です。HEAT値を対象に演算すれば直接下げられ、その演算では HEAT は溜まりません。オーバードライブ中は HEAT が溜まりません。チョコ操作中、カメラはいろいろな角度に自動で切り替わり、右スティックやドラッグで手動にすると一時停止します。演算機は、十字キー／矢印・WASDで選び、Space／J／Enterで押し、Kで実行、Fで分析、Backspaceで1つ戻し、C（コントローラーは RB）でクリア、DeleteまたはQで要素を捨て、Eでドローします。コントローラーは十字で選び、Aで押し、Yで実行、Xで分析、RBでクリア、LBで捨てます。標的の切り替えはこれまでどおり X／Z（RT／LT）です。マウスとタッチでも演算機を操作できます。

ハーバーは鏡面世界のプレイアブルキャラです。現実（三人称）では通常攻撃は使えず、攻撃ボタンで目標を囲む立体の九芒星の陣形に鏡を置きます。鏡は最大9枚で、互いに重なりません。移動しながら押すと目の前に置けます。すでに9枚あるときにさらに置くと、一番古い鏡が割れて置き換わります。目標が変わったり動いたりすると、今ある鏡が陣形の新しい位置へ飛んで並び直します。鏡に敵が映っていると、鏡1枚につき2秒に1HITが入ります（ダメージはありません）。必殺はブラックスポットライト（8秒、14秒ごと）で、手から一番近い鏡へ、鏡から鏡へ乱反射する黒い三角錐の鎖を放ち、鎖の線や鏡の囲みの中の敵を拘束します（動けず、攻撃も始めません）。迅雷ダッシュは、5m以内の鏡があれば自動で狙って飛び込み、鏡の世界へ入ります（なければ普通の迅雷です）。

鏡の世界は一人称で、いられるのは10秒だけです。残り秒数は画面に出て、3秒を切ると赤くなります。時間切れになると、最寄りの鏡から現実へ押し出されます。移動は速く、視点はドラッグ／右スティックです。ハーバーはダメージを受けず、敵は攻撃できず移動だけになり、飛んでいる弾も消えます。攻撃できるのは鏡に映っている敵だけで、巨大なクロー斬撃（5段。最寄りの映った敵へ自動で踏み込み、1段目と4段目でホーミング弾を最大7発）です。ダッシュは、5m以内の鏡から現実へ戻る（出てきた瞬間に映った敵へ一撃）か、鏡がなければブリンクです。コントローラーの Y／キーボードの F で、距離に関係なく最寄りの鏡から現実へ戻れます。現実へ出ると、置いてあった鏡はすべて砕けます。鏡の世界にいるあいだ、ブラックスポットライトの鎖は脱出するまで消えず、その鎖が張られているあいだブラックミラースパイダーが現れます（動かない体長8mの親蜘蛛が約3秒ごとに紫の弾を9発、鎖を走る体長2mの子蜘蛛8匹が2〜4秒ごとに蒼白の弾を6発。現実には出てこず、戻ると消えます）。99HIT以上で、鏡の世界にいるときに必殺ボタンを押すと奥義・鏡映破壊が発動し、鏡の枚数だけ紅のホーミング弾が飛び、親蜘蛛が巨大な紅のエネルギー弾を吐いて、鏡の世界ごと敵と街を粉砕して現実へ戻ります（戻ると鏡はすべて撤去されます）。止めで倒せば ULTIMATE BREAK となり、SSSのまま止めれば隠し評価 X になります。

鏡の世界で与えたダメージは、敵がそこで倒れず（HP1で止まる）、現実に戻ったときに判定されます。目標に届かないと傷は消えて移動操作が10秒逆になり（鏡像化。このあいだは鏡の世界へ入れない）、目標1以上なら半分が反映されて5秒の鏡像化と反射の弾幕がつき、目標2以上ならすべて反映されてペナルティはありません。

テトラは V でハーバーの次に交代でき、操作するのはテトラ、トリアはオートの相棒です。トリアが生み出すブロック（最大9個）を足場にし、通常攻撃は集積と分解炸裂を交互に、必殺はエネミートレース（トレース中にもう一度押すと複製進化）、方向入力なしの迅雷は安全な場所へのテレポート（敵弾の誘導を切る）、99HITでは必殺ボタンで奥義・螺旋です（被ダメージはテトラだけ）。

ヒットをつなぐほど ULTIMATE ゲージがたまり、99HIT でたまりきります（ヒットが2秒半ほど途切れるとヒット数は0に戻ります。奥義のあいだは約9秒）。つないだヒット数に応じて、いまのコンボのランクが表示されます。段階は D（1HIT）凡、C（20）良、B（50）優、A（100）華、S（200）雅、SS（350）絢爛、SSS（500）天衣無縫です。ヒットが途切れても、その戦いでの最高ランクは残ります。また、50HITごとに与ダメージが 1.16 倍ずつ上がります。たまった状態で必殺技を出し、その最中にもう一度必殺の操作をすると奥義になります。セツナは奥義・太陽風が発動し、続いてクレムゾンフレアでレプリカの街が粉々に弾けます。トワは天輪十閃の回転斬りのあいだに奥義・ライトニングプラズマが発動し、続いてライトニングボルトで、中央と場に散開した電流の柱を打ちおろして街を破壊します。奥義の途中は相手のHPが1までしか減らず、止めの一撃（表示 5,000 にヒット補正を掛けたダメージ）で決着します。これで倒したときだけ ULTIMATE BREAK が出ます。倒せないと「耐えた…！」です。ゲージは奥義のあと0からため直しです。街は奥義のあと約2.5秒で元に戻ります。

RESULT のランクは、その戦いでの最高コンボ評価です。クリア時は「RESULT ── 総合評価」で、クリアタイムと残りライフ、最大コンボ、撃破数、ULTIMATE BREAK の回数が付きます。力尽きたときは「GAME OVER」と「あなたの最高評価」で、最大コンボ、撃破数、ULTIMATE BREAK の回数が付きます。SSS（500HIT以上）のまま奥義の止めで相手を倒すと、隠し最高評価 X「神域到達」になります。祝福の文言は「SSSの極致で奥義を決めし者だけが至る、幻の評価。」「──おめでとう。その剣は、神域に届いた。」で、総合評価も X になります。画面は約2.5秒後から、Enter、コントローラーの A（PS5は ×）、またはタップで閉じられます（攻撃・必殺・迅雷・ジャンプでも可）。クリア後は「次のミッション開始！」、失敗後は「再挑戦！」で、同じ相手でもう一度始まります。

ドラゴン戦では、竜のHPが約3%減るごとにダークスピリットが召還されます（最大16体）。スピリットは竜のまわりを回り、セツナへ光弾を放ちます。奥義や街の崩壊が起きると、スピリットも消えます。空はふだんは宇宙で、ヒットやコンボ、必殺のあいだはデータレインの流れる電脳の空に、奥義のあいだはネオンが反転する空に変わります。

C キー（コントローラーは十字→、タッチは「共闘」）でクラウドを呼び出して共闘できます。クラウドはセツナのそばについて歩き、敵が近くにいると「コンパスチェイン」で鎖を振るい、叩きつけます。叩きつけのとき、取りこんだ弾を「弾幕返し」として敵へ跳ね返すことがあります。もう一度同じ操作をすると、クラウドは戻ります。

G キー（コントローラーは十字↑、タッチは「時止め」）で、クラウドの特殊必殺・静止世界〈クロノ・コンパス〉が使えます。セピアの静止空間が広がり、敵と弾の動きが8秒止まります。味方は動けるままです。クラウドが場にいなければ、呼び出してから発動します。

ゴーレム軍団では、ターゲットを切り替えられます。キーボードは X で次、Z で前。コントローラーは RT（PS5は R2）で次、LT（L2）で前。タッチは「標的」。闇のスピリットは対象外です。HPバーは、いま狙っている一体の名前と残量を表示します。

BGM と効果音つきです。BGM は M キー、効果音は N キー、または左上の ♪ と SE でON/OFFできます。

キーボード：移動は WASD または矢印キー。走るは Shift を押しながら移動。攻撃（連打でコンボ）は J またはクリック。迅雷ダッシュ（7m）は K、必殺・月華鎖葬は L（どちらも攻撃でキャンセル）。99HIT以上なら、必殺技中にもう一度 L で奥義。ジャンプは Space、手を振るは E（チョコ操作中はドロー）、背伸びは Q。カメラはマウスのドラッグ、ホイールでズーム。位置リセットは R。相手の切り替え（木人 → ドラゴン → ゴーレム軍団）は T。ターゲット切り替え（次／前）は X／Z。クラウド特殊必殺・静止世界は G。共闘（クラウドを呼び出す／戻す）は C。操作キャラ交代（セツナ → トワ → チョコ → ハーバー）は V。仲間（もう一人を呼び出す／戻す）は B。BGM は M、効果音は N。操作説明の ON/OFF は H、または左上の ？。RESULT のあとは Enter（攻撃・必殺・迅雷・ジャンプでも可）。

攻撃連打：切り抜け×2 → 打ち上げ → 空中切り抜け×2 → 墜天。

コントローラー（Xbox）：移動は左スティック、走るは L3（左スティック押し込み）。攻撃は X、迅雷ダッシュは A、必殺は B（奥義も必殺技中に B）、ジャンプは Y。クラウド特殊必殺・静止世界は十字↑。位置リセットは Menu。相手の切り替えは View、ターゲット切り替えは RT（次）／LT（前）、共闘は十字→、仲間は十字←、操作キャラ交代は RS押し込み、操作説明は十字↓。カメラは右スティック、LB・RB でズーム。PS5 は □ / × / ○ / △、L3、L1・R1、R3、OPTIONS、Create、R2（次）／L2（前）に対応します。背伸びはキーボードの Q か、タッチの「背伸び」です。RESULT のあとは A（PS5は ×）。
